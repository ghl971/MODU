# 墨读 · 沉浸式小说阅读器

一个纯前端、无需后端的沉浸式小说阅读器。支持 TXT / EPUB 导入、在线搜书、多种阅读主题和排版定制，所有数据保存在浏览器中。

> 📖 在喧嚣的世界里，为你留一盏灯、一杯茶、一本好书。

---

## 功能一览

### 📚 书架管理
- 导入本地 **TXT** 文件（自动识别章节标题）
- 导入 **EPUB** 文件（保留章节结构、元数据）
- 在线搜索图书（通过 Open Library API 搜索并加入书架）
- 书籍封面自动生成
- 阅读进度追踪
- 删除导入的书籍

### 📖 沉浸阅读
- 智能段落分段（支持空行分段和逐行分段两种格式）
- 键盘快捷键：← 上一章 · → 下一章
- 阅读进度拖拽跳转
- 完整目录面板，点击任意章节跳转
- 底部控制栏，随时调整阅读设置

### 🎨 主题 & 排版
**6 种阅读主题：**

| 主题 | 风格 |
|------|------|
| 暖纸 | 温润米黄（默认） |
| 怀旧 | 复古棕调 |
| 抹茶 | 清新绿意，护眼柔和 |
| 羊皮纸 | 古卷质感，阅读沉静 |
| 暗夜 | 深色护眼 |
| 墨白 | 清爽极简 |

**4 种正文字体：** 宋体 · 黑体 · 楷体 · 圆体

**排版调节：** 字号（14–28px）· 行距（1.3–2.8）· 段距（0.2–2.0em）

### 🔍 在线搜书
- 搜索 Open Library 的海量图书资源
- 封面预览、作者、出版年份
- 一键加入书架（需通过 HTTP 服务访问，`file://` 协议下受限）

## 快速开始

### 方式一：直接打开（离线阅读）

```bash
# 下载 reader.html，用浏览器打开即可
# 支持 TXT/EPUB 导入和本地阅读
# 注：file:// 协议下在线搜索功能不可用
```

### 方式二：本地服务器（推荐，支持全部功能）

```bash
# Python 3
python3 -m http.server 8080

# 或者 Node.js (npx)
npx serve

# 然后访问
http://localhost:8080
```

### 方式三：部署到 GitHub Pages（在线访问）

```bash
# 1. 在 GitHub 创建仓库
# 2. 上传 reader.html 并重命名为 index.html
# 3. Settings → Pages → 选择 main 分支
# 4. 等待两分钟，即可通过以下地址访问
#    https://<你的用户名>.github.io/<仓库名>/
```

## 使用技巧

| 操作 | 说明 |
|------|------|
| 导入 TXT | 侧栏底部「导入TXT/EPUB」按钮或顶栏「搜索」按钮 |
| 导入 EPUB | 同 TXT，支持批量导入 |
| 在线搜书 | 点击顶栏「搜书」或侧栏「在线搜索」 |
| 目录 | 顶栏「目录」按钮，弹出完整章节列表 |
| 快捷键 | ← 上一章 · → 下一章 · Escape 关闭面板 |
| 侧栏 | 桌面端点击「书架」折叠/展开，移动端滑入 |
| 删除书籍 | 鼠标悬停书架中的书，右侧显示 ✕ 按钮 |

## 技术栈

- 纯 HTML + CSS + JavaScript，单文件无依赖
- 字体：Playfair Display · Noto Serif SC · Noto Sans SC · DM Sans · ZCOOL QingKe HuangYou
- EPUB 解析：JSZip（CDN 加载）
- 图书搜索：Open Library API
- 数据存储：IndexedDB（书籍数据）+ localStorage（设置）
- 协议：MIT
